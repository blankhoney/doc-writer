### 5.2 文档类型模板与示例

本页是维护模板时的说明，运行时不读。运行时入口：

| 用途 | 文件 |
|---|---|
| 选类型与变体、标准章节名 | [类型索引](../../skills/doc-writer/assets/templates/_index.md) |
| 定义文档与五步流程 | [SKILL.md](../../skills/doc-writer/SKILL.md) |
| 按内容选择排版 | [formatting.md](../../skills/doc-writer/references/formatting.md) |
| 示例来源 | [SOURCES.md](../../skills/doc-writer/assets/examples/SOURCES.md) |

所选类型模板仍完整读取。下方规范只在维护模板或选择参考资料时按需阅读，不与运行入口重复维护正文。

#### 5.2.8 模板文件规范

每个类型的详细模板存放在 `assets/templates/{type}.md`，包含：

```markdown
---
type: <类型标识>
category: engineering | knowledge-transfer
default_variant: <默认变体名>
---

# 类型名称
> 一句话定义

## 变体选择
[决策树：什么条件选什么变体]

## 变体 A: <名称>
### 必需内容
[必需内容列表 + 本节回答 + 排版]
### 按需模块
[可用模块 + 格式规范 + 保留条件]
### 示例
[选择必要样本并注明范围与来源，登记到 SOURCES.md]
### 格式规范（可选）
[变体特有的写法规则，如步骤格式、卡片排列规则等]

## 变体 B: <名称>
...

## 类型验证标准
[本类型专用检查项]

## 权威参考
[一线源，标注类型：教写法 / 成品逻辑 / 字段模板]
```

跨模板共有的章节名取自 `assets/templates/_index.md` 的标准章节名表，同一概念不另起名字；只在一个模板里出现的章节用名词短语命名，不必登记。同一类型的各变体同一位置同名，变体只增减章节，不改名。

#### 5.2.9 权威参考源分级

参考源分三类，不混用：

| 类型 | 定义 | 示例 |
|------|------|------|
| 教写法的规范 | 告诉你怎么写这类文档 | Diátaxis 原站、Keep a Changelog、Google Design Docs at Google |
| 成品信息架构 | 做得好的实际文档 | Stripe Docs、K8s API Reference、Django Tutorial |
| 字段模板 | 可填充的结构表 | GitLab issue templates、Nygard ADR 格式、MADR |

真实来源从一线成品取样；范围登记到 SOURCES.md，不使用聚合站转述。

**各类型推荐一线源**：

| 类型 | 教写法 | 成品/字段模板 |
|------|--------|-------------|
| PRD | GitLab 产品开发流 | GitLab feature proposal templates（basic/lean/完整） |
| 技术设计 | Design Docs at Google (industrialempathy.com) | Abseil SWE Book ch10、Google AIP |
| API | Microsoft REST API Guidelines、Google AIP | Stripe Docs、K8s API Reference |
| Changelog | Keep a Changelog、Common Changelog | GitHub Releases |
| 测试 | ISO/IEC/IEEE 29119-3:2021 字段思想（不照搬全套） | — |
| 部署/Runbook | Google SRE Book/Workbook | K8s Configuration Best Practices |
| ADR | Nygard 原文、MADR、adr.github.io | Microsoft Azure ADR template |
| Tutorial | Diátaxis /tutorials | Django Tutorial、Stripe Accept a Payment |
| How-to | Diátaxis /how-to-guides | — |
| Reference | Diátaxis /reference、K8s style guide | K8s API Reference |
| Explanation | Diátaxis /explanation | — |
| README | Standard Readme 规范、GitHub Docs: About READMEs | ripgrep、uv 的 README |
| 通用文风 | Google engineering doc guide、Write the Docs 原则 | — |

#### 5.2.10 扩展机制

新增文档类型时：
1. 在 `assets/templates/` 创建模板文件，遵循 5.2.8 规范
2. 在 `_index.md` 添加索引
3. 类型专用检查项写在模板的"类型验证标准"表里；跨类型的技术或产品要求放进 `references/tech-docs.md` 或 `references/product-docs.md`
4. L0 核心层不需要修改
