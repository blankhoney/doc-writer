# 委托写作

正文默认由主 agent 写。只在两种情况委托子 agent：长文档中相互独立、没有强依赖的章节；主 agent 上下文不足，需要分段处理；用户要求多稿择优（Best-of-N）时生成候选章节。

| 子 agent 类型 | 怎样带上规则 |
|---|---|
| 继承主 agent 上下文的子 agent | 已读规则随上下文带入；仍要补读本任务尚未读到的阶段原文、完整模板和适用规则 |
| 全新子 agent | 在提示里给出包内 `SKILL.md` 和当前模板的绝对路径，要求它先完整读共同约束、当前阶段和适用规则，写稿前补读编写规则；不另复制一份约束 |

子 agent 读过规则不等于遵守规则。主 agent 对产出按 `references/verify-checks.md` 做完整验证：合格才采纳，不合格就修正或重写。
