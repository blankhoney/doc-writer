# 文档类型模板索引

> 第 1 步确定类型后完整读取对应模板，包含变体、条件、类型验证与适用分支。
> 选型流程见 `SKILL.md` 第 1 步；维护模板时见仓库的 `docs/design/5.2-document-templates.md` §5.2.8（不随技能包安装）。

## 工程生命周期文档

| 类型 | 文件 | 默认变体 | 变体数 | 文风 |
|------|------|---------|--------|------|
| PRD | [prd.md](prd.md) | Lean | 4 | 陈述句；需求写成可验证条件，不写实现细节 |
| 技术设计 | [tech-design.md](tech-design.md) | Lean | 4 | 论证式；结论先行，每个取舍带依据 |
| API 文档 | [api-doc.md](api-doc.md) | 端点参考 | 3 | 契约式；现在时，字段、错误码照实写 |
| Changelog | [changelog.md](changelog.md) | Keep a Changelog | 2 | 面向使用者的影响；一条一事，以动作开头 |
| 测试报告 | [test-report.md](test-report.md) | CI 报告 | 3 | 数据式；结论先行，失败与未测如实写 |
| 部署/Runbook | [deploy-runbook.md](deploy-runbook.md) | Deploy Guide | 4 | 祈使句步骤；每步带验证信号，警告放在动作前 |
| ADR | [adr.md](adr.md) | Nygard | 4 | 决策式；"我们将……"，保留决策时的语境 |

**章节名怎么用**：模板表格里的章节名就是文档标题，照写，顺序按模板。结论写在该节首句，不改写进标题。按需模块和自定义节用名词短语命名；How-to 和 Tutorial 的步骤标题用祈使句。规则见 `references/rules.md` 第 1 节。

**标准章节名**：同一概念在所有模板中只用一个名字。外部标准原名在模板中括号注明。生成的文档按文档语言写标准名：中文文档写中文名，英文文档写英文原名。Keep a Changelog 的 6 个分类和 man page 节名会被工具解析，始终写英文原名。

| 标准名 | 写什么 | 不用的名字 |
|---|---|---|
| 概述 | 开头一节：是什么、结论或用途 | 概要、摘要、结论、简介、API 概览、系统概览、架构综述 |
| 背景 | 现状、问题与约束 | 背景与约束、问题、动机 |
| 目标与非目标 | 要达成什么、明确不做什么 | 目标、范围（技术设计与 PRD 中） |
| 设计 | 具体方案；架构、接口、数据、流程作为子节 | 方案、方案设计、实现方案 |
| 备选方案 | 考虑过的现实候选及放弃原因 | 替代方案、Considered Options |
| 代价 | 方案牺牲了什么、已知限制 | 代价与取舍、代价与风险、缺点 |
| 风险 | 可能发生的问题、影响与缓解 | 风险评估、风险分析；测试报告的发布签核写"遗留风险" |
| 未决问题 | 待定事项与决策条件 | 未决、未决项、未决事项、未解决问题、待定 |
| 前提条件 | 开始前必须具备的环境、权限与知识 | 前置条件、前置环境检查、环境要求 |
| 步骤 | 有序操作，每步带预期结果 | 步骤序列、操作步骤、部署步骤 |
| 验证 | 怎样确认结果正确 | 成功验证、验证设计、测试方式 |
| 故障排查 | 常见失败与处理 | 常见错误、常见问题 |
| 回滚 | 撤销操作的步骤 | 回滚/撤销 |
| 联系人与升级 | 负责人和升级条件 | 联系人、升级条件、升级路径 |
| 示例 | 可直接使用的完整示例 | 完整示例、cURL 示例、SDK 示例 |
| 另见 | 相关文档链接，每条一句用途 | 下一步、相关任务、相关参考、深入阅读、文档链接 |

技术设计在同一类型内选架构方案／程序详细设计任务分支，再选原有变体；分支入口见该模板，不增加类型。

## 知识传递文档（Diátaxis）

项目介绍与现有架构说明的独立文档按理解任务选 Explanation，不因读者负责验收就选变更或测试报告。Quickstart 指最快用上真实主要功能：已有会话或工具基础、只想完成一次任务时选 How-to 任务食谱；需要引导学习才选 Tutorial 最短路径，不另建类型。

| 类型 | 文件 | 默认变体 | 变体数 | 文风 |
|------|------|---------|--------|------|
| Tutorial | [tutorial.md](tutorial.md) | 最短路径 | 3 | 第二人称引导；每步有预期结果，不展开原理 |
| How-to Guide | [how-to.md](how-to.md) | 任务食谱 | 2 | 祈使句；假设读者有基础，直达目标 |
| Reference | [reference.md](reference.md) | 键卡片 | 4 | 中性描述；结构对应代码，不给建议 |
| Explanation | [explanation.md](explanation.md) | 概念解释 | 3 | 陈述与论证；可比较和表态，不给操作步骤 |

## 项目首页

仓库根目录的 README 选本类型；它把读者分流到上面各类文档，不替代它们。

| 类型 | 文件 | 默认变体 | 变体数 | 文风 |
|------|------|---------|--------|------|
| README | [readme.md](readme.md) | 工具与库 | 3 | 面向首次访问者；首段陈述，步骤祈使，声明有依据 |
